# Deep-learning-project by Nikoloas Kontoudakis: 283024
Custom NN importer and classification based on adaBelief

download the files by running the following from the project root
``
mkdir -p data
``
### regression
``curl -o data/auto-mpg.data \
  "https://archive.ics.uci.edu/ml/machine-learning-databases/auto-mpg/auto-mpg.data"
``
### classification
``
curl -o data/wdbc.data \
  "https://archive.ics.uci.edu/ml/machine-learning-databases/breast-cancer-wisconsin/wdbc.data"
``
